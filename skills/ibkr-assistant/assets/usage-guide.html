第二块 · 实操层

四步放行，一步都不会跳

只要碰你账户里的数字，都走这四步。你可以把 01 和 02 当成安全区——看到这一步为止， 世界上没有任何一笔单子因为你说了一句话而被发出去。

步骤它做什么你能叫停吗
01 只读查询 读余额、持仓、行情、订单状态。连接本身是只读权限，改不了任何东西。 不用叫停——它本来就没有动账户的能力。
02 dry-run 预演 把方向、数量、价格、保证金、手续费念给你听，然后停下等回复。 随时。不回「确认」就永远停在这一步。
03 --execute 执行 真正发单，只发你这一轮明确确认过的那一笔。换个价格就得重来一遍。 发出去之前可以；发出去之后让你撤单。
04 --live-confirm 账户号 U 开头（真钱）时，再要你亲口说一句「确认实盘下单」。 不说这句话，单子就不会发出去。

先做三步，才连得上

只有这一块需要动手配置。三步做完一次，以后打开客户端就能直接用。

  1. 电脑上打开盈透的客户端，并登录

    两个都行：TWS（Trader Workstation，功能全）或 IB Gateway（更轻，只做连接）。手机 App 不行，必须电脑端。

    客户端必须保持开着并登录。关掉它，我就连不上你的账户了。

  2. 在客户端里打开一个开关

    菜单 File → Global Configuration → API → Settings，勾上 Enable ActiveX and Socket Clients，然后确认一下端口号。

    端口别记错：TWS 模拟盘 7497、实盘 7496；IB Gateway 模拟盘 4002、实盘 4001。 如果连上却发现账户是空的，八成是这里选错了。

  3. 跟我说一句「检查一下连接」

    我会告诉你连没连上、连的是模拟盘还是真实账户、能不能看到行情。确认没问题，就可以开始用了。

    真实账户号以 U 开头，模拟盘以 DU 开头。我会在每次报数字前先说清楚是哪种，避免你把模拟盘的钱当成真的。

常见问题

新手最常问的七个

如果你还有别的疑问，直接问就好——用你自己的说法。

问答层和实操层，我该用哪个？

看你这句话里有没有「我的账户」。问「手续费多少」「内地人能不能开户」，是第一块，不用连任何东西；问「我还有多少钱」「帮我买 100 股」，是第二块，得先把电脑上的客户端开起来。

两层可以在同一个对话里随时切。先问一句规则、再动手下单，很正常。

我完全不懂代码，能用吗？

能，而且你不需要看到任何命令。命令是我在后台用的，你只负责用中文说想做什么、看我用中文回的结果。

唯一需要你动手的是第二块开头的三步配置（开客户端、勾一个开关、说一句「检查连接」）。只问规则的话，这三步都可以跳过。

要花钱吗？需要额外订阅什么吗？

这个助手本身不收费。但有两笔钱是盈透收的，跟助手无关：

行情订阅——想看实时报价要订阅，美股非专业实时打包大约每月 10 美元，当月佣金满 30 美元可免。不订阅也能用，只是报价会延迟十几分钟，我会明确告诉你「这是延迟数据」。

交易佣金——美股固定式每股 0.005 美元、每笔最低 1 美元。这些我都会在下单前算给你看。

它会不会自己偷偷下单？

不会。查数据用的连接是只读的，物理上改不了账户。要下单必须过两道关：先把参数念给你确认，实盘账户还要你再说一次「确认实盘下单」。

而且它不会判断「该不该买」，没有你的明确指令，它什么都不会发。

我的账户信息安全吗？

连接只发生在你的电脑和你的盈透客户端之间，走的是本机端口，不经过第三方服务器，也不上传你的账号。

它不会索取密码或验证码。如果哪天有人用「帮忙配置」的名义问你要 IB Key 验证码，那一定是骗子。

它说的数字准吗？会不会记错？

实测那层的数字——账户、行情、订单状态——都是从你的客户端实时读的，不靠记忆。

问答层的回答（手续费、开户条件、税率）来自整理好的资料，每条都标了核实月份。如果那条信息超过半年，我会主动提醒你「可能已变，建议去官网复核」——政策变得比你想的快。

连不上，一直报错怎么办？

按顺序查三件事：客户端有没有登录；API 设置里的 Enable ActiveX and Socket Clients 有没有勾；端口是不是和客户端一致（模拟盘 7497 / 实盘 7496）。

把报错原文贴给我，我基本能一眼看出卡在哪。常见的是「连上了但账户是空的」——那是端口选错了。

术语速查

这些词听不懂，看一眼就够

我在对话里会尽量避开术语，实在要用的时候会顺手解释。下面是最常出现的几个。

你会听到说白了就是
问答层 / 实操层前一个只查资料、不碰账户；后一个连你的客户端，能看到也能操作真账户。两层互不影响。
只读连接权限上只能看、不能改。查余额和行情都走这个，所以不存在悄悄下单的可能。
dry-run（预演）把一笔单子的参数、保证金、手续费算给你看，但不发出去。你没点头，就停在这一步。
TWS / IB Gateway盈透的两个电脑客户端，必须开着并登录，我才能连上你的账户。手机 App 不行。
模拟盘（纸面账户）假钱、真行情，用来练手。账户号 DU 开头，亏了不心疼。
实盘账户真钱。账户号 U 开头。在这里下单，我会额外要你确认一次。
限价单你指定一个价格，只有到这个价或更好才成交。最常用，也最不容易吃亏。
市价单不管价格，马上成交。价格由市场定，波动大时可能买贵。
保证金开这个仓位要先压住多少钱。不是手续费，平仓后会还回来。
浮盈 / 浮亏还没卖出时的账面赚亏。卖掉之后才变成「已实现」。
购买力账户最多还能买多少，通常比可用资金大（融资账户）。是上限，不是建议。

14 个命令速查

前缀统一是 ./scripts/ibkr.sh。任何命令加 --json 输出结构化数据。前十个属于只读，只有 place-order 与 cancel-order 会动账户。

  • ping — 连通性与账户类型自检
  • account-summary — 净值、现金、购买力、保证金
  • positions — 持仓与成本
  • portfolio — 组合市值与浮盈
  • pnl --wait 3 — 当日、浮动、已实现盈亏
  • quote --symbol AAPL — 报价快照
  • historical --symbol AAPL --duration "30 D" --bar-size "1 day" — 历史 K 线
  • contract-details --symbol ES --sec-type FUT --expiry 202612 — 合约与 conId
  • scanner --scan-code TOP_PERC_GAIN --rows 20 — 扫描器
  • preview-order ... — 保证金与佣金预演（绝不下单）
  • place-order ... [--execute] [--live-confirm] — 下单
  • open-orders — 未成交订单
  • cancel-order --order-id 12345 --execute — 撤单
  • executions — 当日成交
把连接参数固定下来，省得每次敲
export IBKR_HOST=127.0.0.1 export IBKR_PORT=7497 export IBKR_CLIENT_ID=1 export IBKR_ACCOUNT=DU123456

装依赖：python3 -m pip install -r requirements.txt。需要 Python 3.9 以上。
